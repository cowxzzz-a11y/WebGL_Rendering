# Sheet Packer

双击 `open_sheet_packer.vbs` 打开工具。

这个工具用于把一批或多批渲染图拼成雪碧图，不会自动放大图片。单格宽高填 `0` 时，会使用导入图片的实际最大宽高。

## 16 x 2 广告牌流程

1. 把 `列` 设为 `16`，`行` 设为 `2`。
2. `行标签` 默认是 `俯视,平视`，也可以改成任意逗号分隔名称。
3. `导入方式` 默认是 `追加到空槽`。可以直接保持 `导入到：全部槽位`，先导入俯视文件夹，再导入平视文件夹。
4. 如果想手动指定行，也可以把 `导入到` 改成 `第 1 行：俯视` 导入第一批，再改成 `第 2 行：平视` 导入第二批。
5. 确认当前顺序后导出 PNG。

两批图片文件名都叫 `0001-0016` 没关系，只要分两次导入，第二批会进入空槽，不会覆盖第一批。需要重新替换某一行时，把 `导入方式` 改成 `覆盖目标槽位`。

如果单张图片是 `256 x 150`，`16 x 2` 且无间距、无外边距时，导出尺寸就是 `4096 x 300`。

浏览器出于安全限制不会自动读取旁边的图片文件夹，需要在界面里手动选择图片或文件夹。
